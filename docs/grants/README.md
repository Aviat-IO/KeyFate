# Grant-facing security notes

Grant proposals and roadmap materials that describe KeyFate's safety, privacy, decentralization, or censorship-resistance claims should link to the project threat model:

- [Threat model](../threat-model.md)

When writing grant claims, distinguish mitigations from residual risk. KeyFate can reduce single-provider failure, content exposure, and delivery fragility, but it cannot guarantee perfect metadata privacy, disclosure under operator disappearance, resistance to coercion, or correct interpretation of every missed check-in.
